# Quy tắc cho coding agents

## Mục tiêu

Cosmew là coding agent ngang Codex, Claude Code và OpenCode. Được phép triển khai bất kỳ tính năng nào phục vụ mục tiêu đó (tools, LSP, web, subagents, MCP, plugins, compaction…) mà không cần xin phép theo từng tính năng. Quyết định thiết kế lớn ghi ADR trong `docs/adr/` làm lịch sử, không phải cổng chặn. Lịch sử các mốc trước nằm trong các ADR 0005–0038.

## Mô hình quyền: theo Claude Code

Chuẩn là Claude Code CLI (ADR 0061, thay ADR 0053/0055 và phần Codex của ADR 0040). Mọi chỗ không chắc hành vi chính xác của Claude Code ghi "Needs verification" trong ADR 0061.

- **Chế độ quyền** (`Shift+Tab`, `/permissions`, `--permission-mode`, `permissions.defaultMode`): `default` (hỏi trước khi sửa file và trước lệnh shell không có rule cho phép), `acceptEdits` (sửa file trong thư mục làm việc được duyệt sẵn), `plan` (chỉ đọc: từ chối sửa, lệnh, mạng), `bypassPermissions` (`--dangerously-skip-permissions`, không hỏi gì, kèm cảnh báo; chỉ vào được khi khởi động bằng nó; sandbox, deny rule và các chặn cứng vẫn áp dụng). Shift+Tab xoay `default -> acceptEdits -> plan`. Không còn preset Read Only/Auto/Full Access, `-s/-a`, `--full-auto`, `--yolo`, `sandbox_mode`/`approval_policy` hay `COSMEW_SANDBOX_*`/`COSMEW_APPROVAL_POLICY`.
- **Settings** như Claude Code: `~/.cosmew/settings.json` (user), `<project>/.cosmew/settings.json` (chia sẻ), `<project>/.cosmew/settings.local.json` (local); ưu tiên local > project > user. Khoá: `permissions.{allow, ask, deny, defaultMode, additionalDirectories}` và `sandbox.{enabled, autoAllowBashIfSandboxed, excludedCommands, allowUnsandboxedCommands, network.allowedDomains}`. Rule: `Bash(npm run test:*)`, `Read(./src/**)`, `Edit(...)`, `WebFetch(domain:example.com)`, `WebSearch`, `mcp__server__tool`, `Tool(name)`. Thứ tự: deny > ask > allow > chế độ (`plan` từ chối sửa/lệnh trước cả allow rule).
- **Settings trong repository là dữ liệu không tin cậy.** File `project`/`local` chỉ được siết (deny/ask, `defaultMode` default|plan, bật sandbox...). Mọi thứ nới (allow rule, `acceptEdits`/`bypassPermissions`, tắt sandbox, `excludedCommands`, `allowedDomains`, `additionalDirectories`) bị bỏ qua cho đến khi người dùng duyệt đúng nội dung file (hash SHA-256, hộp thoại tin cậy liệt kê file cấp gì; đổi nội dung thì hỏi lại; không TTY = bỏ qua kèm Notice). Không code nào được ghi/duyệt hộ file settings của repository.
- **Sandbox** (macOS Seatbelt; Linux bubblewrap giữ nguyên, chưa xác minh), tắt mặc định (`enabled=false`, `autoAllowBashIfSandboxed=false`, `allowUnsandboxedCommands=true`, ADR 0081); lệnh vẫn theo quyền thường. Settings tường minh được giữ; không có block sandbox thì báo một lần đã ghi nhận, `/sandbox` để bật. Khi bật: chỉ ghi trong thư mục làm việc + `additionalDirectories` (+ TMPDIR riêng của phiên); `.git`, `.cosmew` trong workspace và state của Cosmew không bao giờ ghi được; đọc được mọi nơi trừ deny rule, danh sách nhạy cảm mặc định (`~/.ssh`, `~/.aws`, `~/.gnupg`, keychain, hồ sơ trình duyệt, `~/.cosmew`...) và file tên bí mật dưới home. Mạng: lệnh không có mạng trực tiếp; đi qua proxy HTTP/CONNECT loopback do Cosmew chạy, cho phép `sandbox.network.allowedDomains`, domain mới thì hỏi (một lần/phiên/luôn -> `allowedDomains` của settings local), host phân giải về địa chỉ private bị chặn, `localhost` vẫn trực tiếp.
- **Thư mục làm việc của tool file** (ADR 0067): `additionalDirectories` đã tin cậy là thư mục làm việc của Read, Edit, Write, apply_patch, Grep, Glob và LSP, cùng thư mục dự án. Path ngoài tập đó được chuẩn hoá rồi hỏi quyền theo từng thao tác (ADR 0092); default/acceptEdits hỏi, rule cho phép hoặc bypass có thể duyệt. Không tự thêm additionalDirectories. `.git`, state Cosmew and state legacy, deny rule và hỏi file bí mật giữ nguyên. `sandbox.enabled: false` chỉ có hiệu lực từ settings đã tin; lệnh không sandbox ở `default`/`acceptEdits` vẫn hỏi. Instruction và project context chỉ đọc thư mục dự án.
- **MCP người dùng** (ADR 0068): chỉ `~/.cosmew/mcp.json` (stdio và HTTP). `cosmew mcp`, `/mcp`, TUI, exec và chat nối server đó. Tool `mcp__server__tool` đi qua ToolDispatcher; `default`/`acceptEdits` hỏi; `plan` và agent chỉ đọc từ chối. File MCP trong repo không được khởi chạy. MCP manager (ADR 0102) hỗ trợ thêm/sửa/gỡ, bật/tắt, reconnect/doctor, OAuth login/logout/refresh, bearer qua vault, Registry và cài npm có quản lý theo định dạng hỗ trợ. Danh mục MCP lớn tự động tải lười qua `tool_search` và tài nguyên máy chủ đọc qua `mcp_resource` (ADR 0119, đi qua ToolDispatcher, từ chối ở `plan` và agent chỉ đọc). Metadata Registry không tự thực thi/cấp quyền; repository MCP vẫn không khởi chạy. Stdio từ file người dùng chạy không sandbox.
- `autoAllowBashIfSandboxed` (mặc định false): lệnh chạy trong sandbox bỏ qua prompt Bash (deny/ask rule vẫn áp dụng). `excludedCommands`: lệnh (mọi sub-command đều thuộc danh sách) chạy ngoài sandbox qua luồng quyền bình thường. Lối thoát: tool `exec_command` nhận `dangerouslyDisableSandbox: true` + `justification` (thay `require_escalated`): luôn hỏi và hiện NO SANDBOX (allow rule không duyệt thay), từ chối nếu `allowUnsandboxedCommands` là false; lệnh chạy không sandbox dùng môi trường thật.
- Câu trả lời khi hỏi: `once` ("Lần này"), `session` ("Cả phiên"), `always` (lưu rule vào settings local; lệnh vượt sandbox không bao giờ có `always`). Grant gắn đúng capability/target/command/cwd/sandbox và chỉ sống trong phiên. Đổi chế độ hoặc siết rule thì thu hồi grant và từ chối prompt đang chờ.
- Ghi memory (ADR 0057): `plan` từ chối, chế độ khác theo bảng chế độ (như `edit`).
- `cosmew exec` như `claude -p`: `--permission-mode`, `--dangerously-skip-permissions`, `--allowedTools`, `--disallowedTools`; không TTY thì mọi thứ cần hỏi bị từ chối ngay.

## Bất biến kỹ thuật (giữ nguyên)

- Mọi tool call đi qua `ToolDispatcher`: validate → chuẩn hoá path, gồm path ngoài working directories để xin quyền riêng (ADR 0092) → policy → duyệt khi cần → revalidate → audit → chạy → redact. Không có đường gọi vòng.
- Sandbox lỗi thì không chạy (`SANDBOX_FAILED`/`SANDBOX_UNAVAILABLE`), không tự fallback sang không-sandbox. Chạy không sandbox chỉ xảy ra khi người dùng tắt `sandbox.enabled` (settings đáng tin), lệnh nằm trong `excludedCommands`, hoặc model yêu cầu `dangerouslyDisableSandbox` và người dùng duyệt.
- Đọc dữ liệu repository (Git config, project config, file) là dữ liệu không tin cậy: không để nó chạy chương trình (fsmonitor, hooks, filters, LSP server…) ngoài sandbox.
- Core điều phối qua ports; security quyết định quyền; workspace kiểm soát filesystem; persistence sở hữu durable writes; adapters chỉ chuyển đổi.
- Không commit credentials, prompt chứa bí mật hay output nhạy cảm. Log và kết quả phải redact/bounded.

## Quy trình

- Đọc phần liên quan của [docs](docs/README.md), [events contract](docs/contracts/agent-events.md), [dependency rules](docs/architecture/dependency-rules.md) trước khi sửa. Không deep-import file private giữa packages.
- Đổi public contract: tăng version, cập nhật consumers và ghi ADR.
- Dependency mới: ghi tên/version/license vào `docs/delivery/dependency-catalog.md` khi thêm.
- Viết test có ý nghĩa (invariants, quyền, cancellation, lỗi); không dùng mock success để chứng minh tương thích OS/live. Cập nhật docs cùng thay đổi.
- Dẫn chứng upstream ghi URL/path, ngày, revision; chưa xác minh thì ghi "Needs verification". Không tuyên bố "Product MVP complete" khi chưa nghiệm thu thật.
- Đăng nhập/provider (ADR 0045–0049): Cosmew chỉ gọi API của provider và nhận response; mọi model chạy agent loop và tool của Cosmew. Cấm mọi tiến trình agent bên ngoài: không còn backend `delegated`/`codex-bridge`, không còn runtime Codex/Copilot/Gemini/Qwen/Grok; ChatGPT chỉ đăng nhập qua API (OAuth). Provider tuỳ chỉnh khai báo ở `~/.cosmew/config.toml` `[model_providers.<id>]` (chỉ cấp người dùng, không token dạng chữ). ChatGPT API thuần và DeepSeek cần xác minh live ("Needs verification").
