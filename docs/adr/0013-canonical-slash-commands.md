# ADR 0013: Canonical slash-command discovery

Accepted 2026-11-15 following the explicit user instruction that slash-command names must follow the current Claude Code convention. Supersedes earlier acceptance text advertising FUTRYN-only slash commands as canonical. No dependency, package boundary, storage schema or permission change.

`SLASH_COMMANDS` is the discoverable public registry consumed by autocomplete, command palette and help. It contains Claude-style canonical names only. `/theme` opens the picker without arguments; it is the only theme entry. Prior direct `/theme auto|dark|light` arguments now receive a usage diagnostic; the non-slash CLI `themes set` remains available. retired `/theme set` and `/theme edit` requests receive a clear diagnostic directing users to `/theme`, rather than pretending an editor or a nonstandard command is supported. Existing `/themes` and `/connect` input aliases continue to resolve to their canonical commands; `/connect` is explicitly required by the earlier product request. `/new` and `/reset` resolve to `/clear`; `/cost` and `/stats` resolve to `/usage`, matching the documented Claude aliases. Alias resolution is separate from display so autocomplete renders the canonical name.

Legacy FUTRYN `/switch` and `/accounts` requests remain privately parseable for existing users and are not displayed as Claude commands. `/login` opens account management via Ctrl+A. Switching an account with a populated session requires the existing explicit history-transfer confirmation and uses the same cancellable backend; when there is no history, switching proceeds to model selection. Other unsupported backends continue to return diagnostics. Preserving private compatibility and provider-specific login behavior does not claim full Claude Code compatibility, especially for unimplemented shell, MCP, plugin or compaction backends.

Current [Claude Code command reference](https://code.claude.com/docs/en/commands) was queried through Context7 `/websites/code_claude` on 2026-11-15. It identifies `/theme`, `/clear` with `/new` and `/reset`, and `/usage` with `/cost` and `/stats`. The dynamic documentation index is not an immutable source revision. All registry consumers and tests migrate together; the command-metadata TypeScript shape is unchanged, while the discoverable command set and `/new` behavior are intentionally updated.

## Amendment 2026-11-15

At the user's request `/switch [account]` (alias `/account`) is public again: it appears in `/` autocomplete, `/help` and the command palette. It switches to another connected account and continues the chat in a new account-bound session (ADR 0009); `/login` still manages accounts. `/accounts` and the other legacy names stay parseable but hidden.
