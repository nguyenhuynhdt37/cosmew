# ADR 0119 — Deferred MCP tool search, MCP resources, and round-2 runtime hardening

Accepted 2026-11-26. Shared contract 1.64; SQLite schema remains 13; no new runtime dependencies.

Large user MCP catalogs previously sent every connected tool schema on every model request, inflating input token usage even on turns unrelated to MCP, while MCP server resources and resource templates could not be listed or read. Round-2 auditing also identified edge cases in mid-stream transport error classification, optional usage counter aggregation, MCP archived output identity binding, sandbox IPv6/Bubblewrap path precedence, repository `defaultMode` tightening, and terminal grapheme selection.

When connected user MCP tools exceed the deferral threshold (`> 16` tools or `> 12 KiB` of serialized tool schemas), `McpToolSource` withholds unactivated MCP descriptors from `ToolDispatcher.descriptors()` and exposes `tool_search` (`capability: 'agent.state'`). `tool_search` ranks or selects (`select:mcp__server__tool`, `+required` terms, keyword scoring) matching MCP tools in memory and activates them for the current session so subsequent model rounds receive their full schemas. `tool_search` grants no execution authority: every MCP tool invocation still passes through `ToolRouter`, `mcpValidator`, and `ToolOrchestrator.authorizeMcp`.

`mcp_resource` (`capability: 'mcp.call'`) lists resources (`resources/list`), lists templates (`resources/templates/list`), and reads text resources (`resources/read`) exclusively from connected user-configured MCP servers via `McpHub`. Calls authorize per server (`mcp__<server>__resources_list`, `mcp__<server>__resources_templates`, `mcp__<server>__resources_read`) with server generation identity binding, ask in `default`/`acceptEdits`, respect `mcp__<server>__*` and `Tool(mcp_resource)` rules, refuse in `plan` and read-only subagent profiles, redact all returned metadata/text, omit binary blobs safely, and bind server identity in `OutputArchiveSource` (`CONTRACT_VERSION = '1.64'`). Repository MCP files remain ignored and unstarted.
