# ADR0102 — User MCP manager and managed installation

Accepted2026-11-22. Shared contract1.54; SQLite remains13. User authorized implementation of the MVP from [comparison](../delivery/mcp-manager-comparison-2026-11-22.md).

Cosmew uses one manager for CLI/TUI/host connections. User `mcp.json` remains the configuration source, mutated by persistence through descriptor-relative atomic replacement with locking and byte-revision checks. Repository MCP configurations remain nonexecuting. Unknown fields are preserved; malformed entries remain visible for repair/removal. Enabled/configured, authentication, transport lifecycle and managed artifact state are separate dimensions. HTTP has no invented installed version. Configuration mutations revoke cached grants/pending approvals; exposed MCP descriptors carry connection identity generations so same-name endpoint replacements cannot reuse old pending handlers.

Explicit add/edit/remove, enable/disable, reconnect/doctor, OAuth login/logout and bearer credential operations are human management actions, not model tools. Model MCP calls still flow through ToolDispatcher. Disable removes tools and aborts local owned work; remote cancellation is never claimed to undo side effects. Logout clears local credentials, attempts supported remote revocation and reports the outcome separately. Authentication never reuses model-provider credentials.

OAuth uses MCP SDK1.32.2, PKCE, single-use TTL state, issuer/resource binding, loopback callbacks, scoped secret headers and bounded network targets. Persistent credentials use existing vault via opaque endpoint-bound references. New external dependencies: none. Real provider OAuth/live OS keyring acceptance remains Needs verification; local HTTP fixtures are not real service certification.

Registry metadata and curated candidates are discovery data. Browsing never installs or authenticates. Candidate badges distinguish registry presence and tested status; initial recipes are not certified. Managed installation supports exact npm versions with SHA512 integrity. Automatic resolution initially supports dependency-free packages; transitive dependencies require a complete integrity-pinned npm lock v3. Installation uses npm ci with scripts disabled, owned private directories and no repository/user npm config. Failed/cancelled installs clean their owned artifacts. Remote recipes configure URLs without downloads. General arbitrary package/runtime installation, update/rollback, executable plugins and enterprise catalogs remain expansion work.

The TUI supplies Configured/Discover/Recommended, safe confirmation, masked bearer entry, tool inspection, diagnostics, pagination and cancellation. CLI mirrors the host APIs while keeping legacy mcp list shape; `list --managed` provides separated state. All inputs and outputs are bounded/redacted. See [auth](../delivery/mcp-authentication.md), [installer](../delivery/mcp-managed-install.md) and the delivery report for tests and limits.

Source docs checked2026-11-22: https://code.claude.com/docs/en/mcp · https://learn.chatgpt.com/docs/extend/mcp · https://opencode.ai/docs/mcp-servers.md · https://modelcontextprotocol.org/registry/about. This is a Cosmew design, not an assertion of full upstream runtime parity.
