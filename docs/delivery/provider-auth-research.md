## Library decision

| Concern | Vercel AI SDK 7.0.173 | @opencode/ai 2.3.0 |
|---|---|---|
| API/runtime | Framework-independent generation functions and protocol adapters | Schema-first routes with shared managed Effect runtime and Promise facade |
| Protocol coverage | Native provider packages and separate Chat/Responses model constructors | Explicit many-provider routes, media, decisions, continuation/advanced APIs |
| Credential ownership | Explicit apiKey/custom fetch allows injected vault resolution | Config/auth options; also cloud auth dependencies |
| Scope/dependencies | Core brings gateway/provider-utils; only selected adapters imported | Effect, OpenCode schema, AWS/Smithy, Google auth even for narrow slice |
| Hannes fit | Selected; use primitives only, never SDK agent execution | Viable alternative, deferred because wider runtime/schema coupling |
| Evidence boundary | Exact package versions, typecheck and wire fixtures required | README/source/package evaluation only; no runtime compatibility claim |

Catalog freshness: timestamp each account-specific provider listing; cache is explicitly stale on offline fallback. Optional Models.dev synchronization supplies metadataSource/metadataFetchedAt and limits/prices only; capability fields remain unknown until independently verified. No fixed model ID list is shipped as discovery.

Routing/retries: explicit model/account selection, unknown capability rejection, bounded request/response sizes, no fallback across accounts/providers, no automatic retry for generation with uncertain remote acceptance. Safe catalog GET uses bounded exponential jitter and Retry-After. Model switching resets conversation context, preventing unapproved prompt transfer.

Subscription recommendation: API accounts work independently of consumer plans. Codex/Gemini/Claude/Qwen delegated CLIs and GitHub Copilot SDK/auth need a separate integration with enforceable Hannes permission ports and provider-approved credentials/client registration. No token/cookie scraping, no borrowed first-party clients. Copilot REST/Models entitlements are not assumed from a Copilot plan. These delegated integrations remain Not implemented, not simulated OAuth.

Limitations: upstream code/docs evolve; source availability is not a legal compatibility opinion. No paid plan, API credentials or live vendor generation evidence was supplied by research. Cloud adapters and Tier 2 presets are not shipped solely because an SDK lists them. See the acceptance report for actual tests.
