3. **Memory recovery:** persistent kernel locks release on process death; bounded contention retries and immediate same-process refusal avoid unsafe stealing/deadlock. A bounded metadata journal reconciles interrupted file/index/counter updates without replaying memory bodies over user edits. Temporary-file cleanup progresses before the entry quota check. Invalid journals normalize to STORAGE. Legacy ownerless directory locks need the documented manual recovery after stopping all users. Native evidence is macOS/Bun; Linux and hardware power-loss remain Needs verification. [ADR 0057](../adr/0057-user-scoped-project-memories.md).

Exact preimage hashes/modes protect parent changes, including whitespace/chmod changes. Secret-bearing automatic patches are suppressed rather than altered. Changed worktrees stay available until explicit verified cleanup. Binary, symlink, actual mode/encoding changes and oversized results retain explicit manual-review paths. New nonexecuting files respect 0644 masked by the host umask (0600 under077); more restrictive source permissions are not widened. Existing executable scripts preserve parent permissions. Patch JSON remains capped2200 characters/32 reviewed paths; base blobs16KiB. [ADR 0097](../adr/0097-worktree-review-handoff.md).
5. **Quality gate:** default tests include tests/apps/packages; one quality entry runs typecheck/lint/tests, with separate native/PTY/live entries and explicit paid-call opt-in.
