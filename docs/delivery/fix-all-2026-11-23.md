# Audit fixes — 2026-11-23

This change set addresses the failing checks, rendering performance and stale command/documentation metadata identified in [the audit](next-priorities-2026-11-22.md). The shared dirty working tree is preserved; source fixes are not a claim that installed binaries, every provider or every OS have been certified. Deferred MCP discovery, executable hooks, MCP resources and IDE integration remain separate feature work.

Three subagent assignments cover long-chat rendering, provider/MCP test contracts, and memory/context/migration/theme fixtures. Root owns canonical command metadata, integration review and the aggregate quality gate. No commits/staging, user-state restoration, paid generation or competitor agent embedding is performed.

## Provider retry and MCP bounds

Provider replay fixtures now derive their binding from public fixture account/provider/request values and valid Responses SSE. The investigation additionally reproduced duplicate requests after text or a tool call had already been observed. Adapter recovery is now refused after any non-started event and after cancellation. OAuth Responses `generate()` delegates recovery to `stream()` instead of retrying a third time after two encrypted-history rejections. Original replay-bound requests/history are preserved. See the dated correction in ADR 0082. Provider/privacy/adapters/MCP focused tests: 69 pass, 0 fail, 302 assertions.

MCP size tests use the actual configured/default response ceilings: exact limit, limit+1 JSON bytes, clipped output below the 2 MiB response ceiling, and an oversized open SSE stream that must cancel without waiting for EOF. No MCP production behavior or size ceiling was weakened to accommodate the tests.

## Rendering and review

The word-oriented wrapper avoids allocating an object for every grapheme and preserves existing styled-word/Unicode/CRLF semantics. Content-weighted LRU caches constrain retained source payload estimates. Independent review found tool input/part/hook payloads missing from the first cache estimate; a private structural weigher with WeakMap caching, early cutoff and depth/cycle handling now includes them. Tool-only and hook-only large item tests failed against the previous estimator and pass after correction. These are payload estimates, not an exact process heap cap. Performance budgets remain unchanged. Full aggregate outcome is recorded below after the final run.

## Additional aggregate findings

The first integrated quality run passed typecheck/lint and all previously failing audit cases, including the high-load giant-paragraph test: paint 10 ms, typing 2.5 ms, next delta 11 ms and settled Esc 157 ms. It finished with 2,075 pass / 13 skip / 2 fail, 2,090 tests across 231 files, 526.12 seconds. The two newly observed failures were retained and addressed rather than ignored:

- The legacy Seatbelt candidate cleanup fixture aborted after 150 ms from before sandbox launch and expected a child PID even if startup had not completed. It now independently observes a UUID-marked real child before cancellation, uses an explicit startup-inclusive five-second runtime timeout, checks output PID against the observed identity, and retains the existing 2.5-second child-disappearance bound. Test harness timeout accounts for the actual five-second timeout case; no production timeout/containment behavior changes. Focused native regression: 1 pass, 0 fail, 8 assertions.
- Background-task history ran the global ordered pruning query after every save, even when the table was already within its 5,000-row bound. The existing retention regression reproduced in isolation at 6.19 seconds against its unchanged five-second test deadline. An in-transaction SQLite count now gates the expensive global prune; counts are never cached across transactions, per-owner pruning still runs, and over-limit global rows are removed before commit. The same full retention/rollback/reopen suite passes, with the retention case at 1.84 seconds. No schema/version or retention-order change is needed.

A final full quality rerun on the completed source follows; these focused results alone are not the final acceptance.
