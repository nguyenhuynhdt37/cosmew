# GitHub Themes and Picker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Cosmew's colour themes with the nine GitHub (Primer) themes, add "Sync with system" (light/dark theme pair), and rebuild `/theme` with a dialog-local preview that never re-renders the app behind it.

**Architecture:** Palettes are generated once from Primer CSS into a committed TS module. A pure `themeView()` turns a manifest + mode + capability into the theme context value (cached per manifest), used both by the app-wide `ThemeProvider` and a new `ThemePreviewScope` that wraps only the preview. The picker keeps the highlighted theme in local React state and touches the engine only on Enter.

**Tech Stack:** Bun 1.4.4, TypeScript, React/Ink 8.0.0, zod (contracts), `ink-testing-library`.

**Spec:** `docs/superpowers/specs/2026-11-28-github-themes-design.md`

## Global Constraints

- No new runtime dependency; `@primer/primitives` (MIT) is read once by a script, never imported.
- Record Primer source URL, exact package version and access date in ADR 0127 and in each preset's `attribution`.
- Theme ids: `github-light`, `github-light-high-contrast`, `github-light-colorblind`, `github-light-tritanopia`, `github-dark`, `github-dark-high-contrast`, `github-dark-colorblind`, `github-dark-tritanopia`, `github-dark-dimmed`.
- Kept ids: `auto`, `dark`, `light`, `dark-ansi`, `light-ansi`. `auto` stays the default theme.
- Removed ids map: `midnight → github-dark-dimmed`, `parchment → github-light`, `dark-daltonized → github-dark-colorblind`, `light-daltonized → github-light-colorblind`.
- New appearance fields: `syncWithSystem: boolean = false`, `lightTheme = 'github-light'`, `darkTheme = 'github-dark'`; in sync `mode` is stored as `system`.
- Contract version `1.71 → 1.72`; ADR `docs/adr/0127-github-themes-and-sync-appearance.md`.
- Shared working tree: commit only your own hunks (`git add -p` / explicit paths), never stash.
- Run `bun run format` before each commit; `bun run lint` and `bun run typecheck` must pass at the end.
- Docs are mostly Vietnamese; update `CLAUDE.md` appearance paragraph and `docs/product/feature-parity.md` in the last task.

## Review Focus

1. A user whose `settings.json` holds `theme: "midnight"` (or any removed id) upgrades → loads `github-dark-dimmed`, no error, no warning spam. (Task 3)
2. Sync mode while the terminal background answer (OSC 11) arrives *after* startup → active theme flips to the matching slot without reopening anything. (Task 3)
3. A 16-colour terminal selecting a GitHub theme → falls back to `<mode>-ansi` tokens like `auto` does, never prints truecolor escapes. (Task 3)
4. Esc (or closing the dialog any other way) after browsing many themes → committed theme and the screen behind are unchanged; nothing to roll back because nothing was previewed globally. (Task 5)
5. Very narrow terminal (40 cols, 15 rows) opening `/theme` in sync mode → the dialog still shows the list, both slots and a compact preview without overflow. (Task 6)
